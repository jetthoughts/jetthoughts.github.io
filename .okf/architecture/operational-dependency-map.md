# The one rule that governs it

Sam arrives owning exactly three things: a rough idea, a Gmail account, and a
browser. Every other account, template, tool, and artifact is set up or
produced during the course - no Stripe account, ad account, Lovable
subscription, domain, or GitHub account may be assumed to exist on Day 1.
Any lesson edit that assumes a fourth original input is a defect.
