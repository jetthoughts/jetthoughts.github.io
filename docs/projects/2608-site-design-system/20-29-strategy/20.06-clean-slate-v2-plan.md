## Why (one paragraph)

Paul's direction: the site must read as a **top-tier service with a top-tier
UI**, and the current CSS — recovered from an obfuscated export — is not the
foundation to build that on. The session evidence agrees: every born-clean page
shipped without reverts (blog rebuild 0 fl-lines, blog-single 2, course 11,
vibe-code-rescue, friday-report), while every legacy-propagation attempt failed
(1a.4 footer reverted; 41-rule eyebrow sweep reverted on AA; #540's first
attempt created the seam it removed; buttons = 780 sites, never started). So:
**stop patching legacy; build v2 clean; run both; cut over page by page**, with
a non-indexed `/next/` path on production for live testing.
