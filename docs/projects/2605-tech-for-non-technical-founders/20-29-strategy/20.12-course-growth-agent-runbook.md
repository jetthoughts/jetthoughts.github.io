- **Why**: 0 of ~580 blog posts link to the course; internal linking is SEO
  hygiene, independent of the pilot gate.
- **Tools**: rg, Edit, chrome-devtools for scroll gate.
- **Steps**: (1) shortlist 8-12 EVERGREEN posts by topic match - rg blog
  content for: idea validation, MVP, first customers / first paying, hiring
  a developer / dev shop, non-technical founder, landing page test, customer
  interviews. Prefer posts already ranking (check GA4 top blog pages if
  accessible, else topical judgment). (2) Add ONE short house-style callout
  per post linking the MATCHING module/lesson (not always the landing page -
  deep-link 2.1 for interview posts, 4.1 for hiring posts, etc.).
  (3) Callout copy must pass voice gates; no two posts may reuse the same
  callout sentence (rotation rule).
- **DoD**: 8-12 posts each carry one callout; scroll gate screenshots per
  post; `bin/rake test:critical` green; one PR.

### G2.2 SERP + metadata spot-check

- **Tools**: browser (search engine), Edit.
- **Steps**: search the course's target phrases from the landing/lesson
  keywords (e.g. "non technical founder course", "validate startup idea
  course free", "idea to first paying customer"). Record position +
  which page appears + how the snippet reads. Fix ONLY metadata gaps found
  (missing/weak description, truncated title). No keyword stuffing, no
  new content.
- **DoD**: a SERP-snapshot table appended to this runbook (query, position,
  page, snippet issue, fix applied); metadata edits in the same G2 PR.
