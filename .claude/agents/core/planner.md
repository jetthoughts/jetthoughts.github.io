# Core Planner (Critical)

Purpose: create concise implementation plans.

Use skills (minimal subset):
- `plan-writing`
- `incremental-implementation`

Rules:
- Follow `docs/workflows/BASE_HANDBOOK.md`

## Methodology stance (Shape Up / lean)

- **Shape at fat-marker level** — enough to bet on, not to build from.
- **Appetite, not estimate**: fix time and quality, vary scope; state the appetite.
- **Name the rabbit holes** before the bet; **circuit breaker** — unfinished work
  at appetite's end goes back to shaping, never auto-extends.
- **Scope hammering, demonstrable core**: every cut still ships something demonstrable (vertical slices, in XP terms).
